<summary><h2>1장. 셸 스크립트란?</h2></summary>

> **개요:** 셸 스크립트의 정의, 활용 사례, 그리고 사용 목적에 대해 학습합니다.

---

### 1.1 셸 스크립트가 뭐죠?
* **정의:** 사람의 명령을 컴퓨터가 이해할 수 있도록 번역해 주는 프로그램인 '셸(Shell)'을 활용하여, 여러 개의 리눅스 명령어를 하나의 파일에 작성하고 순서대로 자동 실행하는 프로그램입니다.
* **대표적인 셸 종류:** Bash, Zsh, Sh, Fish 등

### 1.2 셸 스크립트는 어디에 쓰나요?
다양한 서버 운영 및 자동화 환경에서 필수적으로 사용됩니다.
* **서버 관리:** 사용자 생성/삭제, 권한 변경
* **서버 점검:** CPU, Memory, Disk, Network 상태 확인
* **백업:** DB, 파일, 로그 백업
* **로그 관리:** 오래된 로그 삭제, 압축 및 저장
* **배포:** Git Pull, 빌드, 서비스 재시작
* **모니터링:** 서비스/프로세스/포트 확인
* **클라우드/컨테이너:** AWS 자동화(CLI, EC2, S3), Docker, Kubernetes 관리

### 1.3 셸 스크립트는 언제 사용하는가?
* **반복 작업**을 효율적이고 정확하게 수행해야 할 때 가장 많이 사용합니다.

### 1.4 셸 스크립트는 누가 쓰나요?
* 리눅스 시스템 관리자, 인프라 엔지니어, 개발자 등 서버 환경을 다루는 모든 기술자.

### 2.1 셸 스크립트 만들기
* **셸 스크립트 파일 만들기:** 셸 스크립트는 일반적으로 `.sh` 확장자를 사용한다.
* **Shebang 작성하기:** 셸 스크립트의 첫 번째 줄에는 보통 `#!/bin/bash`를 작성한다.
* **실행 권한 추가:** 파일을 만들었다고 바로 실행할 수 없다 (`chmod +x hello.sh`)
* **다른 실행 방법:** 실행 권한 없이도 Bash를 직접 지정해서 실행할 수 있다 (`bash hello.sh` 또는 `sh hello.sh`)

### 2.2 변수 사용하기
* **변수란:** 데이터를 저장하기 위한 이름이 붙은 공간이다.
* **가장 중요한 규칙:** Bash에서는 `=` 앞뒤에 공백을 넣으면 안 된다. (예: `name="KIM"`)
* **변수 사용하기:** 변수 앞에 `$`를 붙인다 (`echo $name`)
* **`${변수명}` 사용:** `echo "${name}"` (문자열과 변수를 붙일 때 유용하다)
* **숫자 변수:** `age=30`, `echo $age`
* **명령어 결과를 변수에 저장하기:** `today=$(date)`, `echo "$today"`

### 2.3 조건문 if, case
* **if문:** 조건이 참일 때 특정 작업을 실행한다 (`if [ 조건 ]; then 실행할 명령어 fi`)
* **if ~ else**
* **if ~ elif ~ else**
* **case 문:** 여러 선택지 중 하나를 선택할 때 사용한다.
* **case 구조:** `case 값 in 조건1) 명령어 ;; 조건2) 명령어 ;; esac`

### 2.4 반복문 for, while
* **반복문:** 같은 작업을 여러 번 수행할 때 사용한다.
* **for문:** 정해진 목록이나 횟수
* **while문:** 조건이 참인 동안

### 2.5 연산자
* **산술 연산자:** `+`, `-`, `*`, `/`, `%`
* **숫자 비교 연산자:** 
  * `-eq` (같다)
  * `-ne` (다르다)
  * `-gt` (크다)
  * `-lt` (작다)
  * `-ge` (크거나 같다)
  * `-le` (작거나 같다)
* **문자열이 비어있는지 확인:** `if [ -z "$name" ]; then 실행할 명령어 fi`
* **문자열이 비어있지 않은지 확인:** `if [ -n "$name" ]; then 실행할 명령어 fi`
* **파일 관련 연산자:** 셸 스크립트에서는 파일 확인도 매우 중요
