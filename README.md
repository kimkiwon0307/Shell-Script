<summary><h2>1장. 셸 스크립트란?</h2></summary>

> **개요:** 셸 스크립트의 정의, 활용 사례, 그리고 사용 목적에 대해 학습합니다.

---

### 1.1 셸 스크립트가 뭐죠?
* **정의:** 사람의 명령을 컴퓨터가 이해할 수 있도록 번역해 주는 프로그램인 '셸(Shell)'을 활용하여, 여러 개의 리눅스 명령어를 하나의 파일에 작성하고 순서대로 자동 실행하는 프로그램입니다.
* **대표적인 셸 종류:** Bash, Zsh, Sh, Fish 등

### 1.2 셸 스크립트는 어디에 쓰나요?
다양한 서버 운영 및 자동화 환경에서 필수적으로 사용됩니다.
* **서버 관리:** 사용자 생성/삭제, 권한 변경
* **서버 점검:** CPU, Memory, Disk, Network 상태 확인
* **백업:** DB, 파일, 로그 백업
* **로그 관리:** 오래된 로그 삭제, 압축 및 저장
* **배포:** Git Pull, 빌드, 서비스 재시작
* **모니터링:** 서비스/프로세스/포트 확인
* **클라우드/컨테이너:** AWS 자동화(CLI, EC2, S3), Docker, Kubernetes 관리

### 1.3 셸 스크립트는 언제 사용하는가?
* **반복 작업**을 효율적이고 정확하게 수행해야 할 때 가장 많이 사용합니다.

### 1.4 셸 스크립트는 누가 쓰나요?
* 리눅스 시스템 관리자, 인프라 엔지니어, 개발자 등 서버 환경을 다루는 모든 기술자.

<summary><h2>2장. 셸 스크립트 기초 문법</h2></summary>

> **개요:** 셸 스크립트를 생성하고, 변수 활용 및 조건문 사용법을 학습합니다.

---

### 2.1 셸 스크립트 만들기
1. **파일 생성:** `touch hello.sh`
2. **Shebang(시뱅) 작성:** 첫 번째 줄에 `#!/bin/bash` 추가 (Bash 셸로 실행함을 명시)
3. **내용 작성:** `echo "Hello world"` 등 명령어 작성
4. **실행 권한 부여:** `sudo chmod +x hello.sh`
5. **실행:** `./hello.sh`

### 2.2 변수 사용하기
* **사용 이유:** 같은 값을 여러 곳에서 사용할 때 값을 한곳에 저장하여 유지보수성과 가독성을 높이기 위해 사용합니다.
* **변수 선언:** `name="Kim"` (주의: `=` 양쪽에 공백 금지)
* **변수 출력:** `echo $name` 또는 `echo "${name}"`
* **명령 결과 저장:** `today=$(date)` 또는 `today=`date``
* **예제:**
  ```bash
  today=$(date +%F)
  echo "$today"
